# Changelog

All notable changes to `filament-goatcounter` will be documented in this file.

## 3.0.0 - 2026-10-08

First release for Filament 5.x.

GoatCounter for Filament on top of [laravel-goatcounter](https://github.com/jeffersongoncalves/laravel-goatcounter):

- Script injected at `PanelsRenderHook::HEAD_START` once the settings are complete
- Settings page with validation
- `->settingsPage(false)` for injection only
- Translations in 19 languages
